Datenabgleich

Deutsche Pokémon-Karten werden primär über TCGdex gesucht; die Pokémon TCG API dient als unabhängiger Fallback. YGOPRODeck und OPTCG API bleiben für die anderen Kartenspiele erhalten. Einzelne Serverfehler brechen die Erkennung nicht ab; OCR-Merkmale und manuelle Eingabe bleiben verfügbar.

Vorgrading

Der Score ist eine grobe Smartphone-Vorprüfung und kein offizielles PSA-, CGC- oder TAG-Grading. Echtheit und Zustand werden getrennt behandelt.
